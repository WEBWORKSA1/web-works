Lookups run from your browser to public DNS and registry services. Some registries limit how often one visitor may query them; Registry mode pauses between names for that reason.

Fast vs registry mode

Fast mode asks DNS whether each name has nameservers. Registered names almost always do; a “no such name” answer from the extension’s servers means nobody holds it. It’s the quickest way to filter a long list.

Registry mode reads each name’s RDAP record, the same data the domain lookup shows. Use it when you need expiry dates or registrars, for example to plan renewals across a portfolio.
