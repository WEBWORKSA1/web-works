Which tool do I need?

  • “Is this name available?” Start with the domain lookup, or the bulk checker for a list.
  • “Why is my email going to spam?” Run the health check.
  • “Did my DNS change go live?” Use the DNS lookup with resolver comparison.
  • “Is someone impersonating us?” Scan with the lookalike finder.
